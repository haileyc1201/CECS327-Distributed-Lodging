# System Overview

Our system is a distributed lodging reservation platform similar to Airbnb.

The system includes:

- guest users who search properties and make reservations
- host users who create listings and manage availability
- backend management of users, listings, availability, reservations, reviews, and payments
- multiple backend services that communicate as one system

The system also needs to prevent conflicting reservations and continue operating when individual components or communication links fail.
