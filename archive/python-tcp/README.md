# Archived Python TCP microservices

These files are the original Milestone 1 Python TCP services (Property, Reservation, Payment)
plus Flask gateway and TCP demo client.

**The current stack is Node.js HTTP** under `services/` at the repo root.
Do not use these for the primary demo unless you intentionally want the legacy TCP path.

Dependencies (archived): see `requirements.txt` in this folder (`flask`, `flask-cors`).
